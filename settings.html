About AetherVoice

The native, local-first dictation utility built as a privacy-respecting alternative to Aqua Voice.

AetherVoice uses Tauri v2, native CPAL audio capture, and embedded quantized Whisper models to provide instant, system-wide speech-to-text with zero cloud subscription fees.

Framework: Tauri v2 (Rust + TypeScript)
Audio Subsystem: CPAL (Windows WASAPI)
Default Model: Whisper Large-v3-Turbo Q5_0 GGUF
Input Synthesis: Win32 SendInput Virtual Keystroke Injection
