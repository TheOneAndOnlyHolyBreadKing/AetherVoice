About AetherVoice & Engine Architecture

The native, 100% local-first speech dictation engine engineered for privacy, ultra-low latency, and intelligent transcription.

AetherVoice is a zero-cloud, high-fidelity voice dictation system. Operating entirely on your local machine, your audio, transcriptions, and screen context never touch an external server or relay.

Core Architecture: Tauri v2 (Rust + TypeScript + HTML/CSS)
Speech-to-Text Subsystem: OpenAI Whisper Large-v3-Turbo (Local GPU Inference)
Audio Capture Subsystem: Native CPAL (Windows WASAPI loop, 16kHz 32-bit float mono)
Reasoning & Rewriting Engine: Local Ollama LLM (Gemma 2, Llama 3.2, Qwen 2.5, DeepSeek)
Screen Context Engine: Win32 Deep Context API (Active window and process detection)
System Text Injection: Win32 Virtual Keystroke Synthesizer (Zero-clipboard fallback)
Network & Privacy Guarantee: 100% Offline · 0 Bytes External Network Transit · No Telemetry · No Cloud Relays
